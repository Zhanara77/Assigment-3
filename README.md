# Assignment 3 — Steppe Escape

## Topic
Responsive travel guide about Kazakhstan.

## Task 1
The "Places worth discovering" section is responsive using only my own CSS:
- mobile: 1 card per row
- tablet (768px+): 2 cards per row
- laptop (992px+): 3 cards per row
- heading size and section spacing also change

No Bootstrap classes are used inside this section.

## Task 2
The rest of the page uses Bootstrap 5.3:
- responsive navbar
- container / row / col-* grid
- order-* classes
- d-none / d-md-block
- d-flex and utility classes
- responsive cards
- accordion component

## Task 3
The report compares the hand-written media-query approach with Bootstrap.
