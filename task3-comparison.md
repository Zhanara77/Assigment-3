# Task 3 comparison table

| Criterion | Task 1 — Own CSS | Task 2 — Bootstrap |
|---|---|---|
| Amount of code | I wrote the grid, breakpoints and spacing myself. | Bootstrap provides many grid and utility classes, so less custom CSS is needed. |
| Control over design | I have direct control over every rule in the destination section. | Bootstrap gives a predefined system, while my CSS can still customize it. |
| Speed of work | It takes more time because I create the responsive rules myself. | It is faster because Bootstrap already provides responsive grid and components. |
| Ease of changes | Changes are made by editing my CSS media queries. | Many layout changes can be made by changing Bootstrap classes. |

I would choose hand-written media queries when I need precise control over a specific section. I would choose Bootstrap when I need to build a responsive page quickly and use ready-made components such as a navbar, cards or accordion.
